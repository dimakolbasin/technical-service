# Suggested commands

- Development: `npm run dev`.
- Production preview: `npm run build && npm run serve`.
- Format: `npm run format`; verify formatting: `npm run format:check`.
- Type/Astro diagnostics: `npm run check`.
- Main verification: `npm test`.
- Browser/visual tests: `npm run test:e2e`.
- Build parity and budgets only: `npm run verify`.
- Inspect changes: `git status --short`, `git diff --check`.
